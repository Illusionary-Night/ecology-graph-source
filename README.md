# 失控的生態池

一款以七種生物構成的食物網為核心的生態模擬遊戲。模擬會逐 Tick 計算族群數量、能量、捕食、繁殖、季節、年齡與植物種子庫；畫面中的生物圖示是狀態的視覺呈現，不會另外改變模擬數值。

專案使用原生 JavaScript ES modules、HTML Canvas 與 CSS，沒有第三方執行期套件。引擎邏輯在 `src/engine/`，瀏覽器介面在 `src/ui/`。

## 遊戲模式

- **新手教學**：逐步介紹生態池、族群數量、能量、速度與圖表，並提供一次操作練習。
- **一般模擬**：自由調整各物種數量，觀察食物網變化；目前是沙盒模式，沒有勝負條件。
- **三選一模式**：先經過觀察期，再進行六個事件選擇回合。每次選擇後模擬會持續到穩定或逾時；任何物種滅絕即失敗，完成六回合且無滅絕即勝利。
- **無盡模式**：持續選擇事件牌，牌可以在不同回合重複；任何物種滅絕即結束，並記錄撐過的回合數。

遊戲頁提供暫停、速度控制、主選單、六位種子碼、數量變化圖，以及三選一／無盡模式的局面紀錄。複製的紀錄包含種子碼和選擇順序，可用來重現遊戲。

## 本機執行

在專案資料夾啟動靜態伺服器：

```sh
python3 -m http.server 8000
```

接著用瀏覽器開啟 <http://localhost:8000>。ES modules 需要透過本機伺服器載入，不要直接用 `file://` 開啟 `index.html`。

## 測試與建置

```sh
npm test       # 執行 Node 內建測試
npm run build  # 建立版本化發布檔到 dist/
```

不需要 `npm install`；專案沒有外部套件依賴。測試涵蓋引擎、事件牌、穩定度與歷史資料、種子碼、紀錄和建置流程。瀏覽器端的完整操作流程目前沒有自動化 UI 測試。

## 網址參數

- `?mode=game`：直接開始三選一模式。
- `?mode=endless`：直接開始無盡模式。
- `?code=XXXXXX`：指定六位種子碼；字元不含 `I`、`O`、`0`、`1`。
- `?seed=12345`：以舊式整數種子指定起點。
- `?speed=500`：指定一般模擬的初始速度，支援 `1`、`2`、`5`、`10`、`50`、`100`、`500`。三選一與無盡模式開局會固定從 500× 開始。
- `?picks=0,2,1`：重播選擇順序；`0`、`1`、`2` 分別代表每輪第一、第二、第三張牌。
- `?autopick=1`：自動選擇每輪第一張牌，主要供重播或檢查流程使用。

如果程式碼有更新但瀏覽器仍顯示舊畫面，可強制重新載入以清除快取。

## 專案檔案

```text
src/engine/       純模擬邏輯：狀態、參數、隨機數、捕食、繁殖與遊戲流程
src/ui/           Canvas 場景、圖表、介面、種子碼與局面紀錄
src/ui/assets/    生態場景使用的物種圖示
tests/            Node 內建測試
tools/build.mjs   產生帶內容版本號的 dist/ 發布檔
SPEC.md           目前的模擬與遊戲規格
PROTOTYPE_NOTES.md 原型決策與調參歷史；早期記錄未必代表目前實作
TESTING.md        玩家試玩說明與回報方式
```

## 文件維護

`SPEC.md` 描述目前採用的規則；預設數值的唯一程式來源是 `src/engine/params.js`。改動模擬或遊戲規則時，請同步更新規格與相關測試。`PROTOTYPE_NOTES.md` 是歷史紀錄，請勿將其中較早的數值或介面描述當成現況。

## 協作與開發約定

- 每位開發者使用獨立分支（`feature/名字-功能`），完成後建立 Pull Request，不直接推送至 `main`。
- 合併前須執行 `node --test`，確認所有測試通過。
- 修改 UI 時，須維持模擬引擎與畫面呈現的獨立性，不得因視覺呈現而改變模擬結果。
- 模擬參數統一由 `src/engine/params.js` 管理，隨機數統一由 `src/engine/rng.js` 處理。
- 修改牌組或模擬參數時，須重新驗證單張事件牌獨立套用於預設環境時不會造成物種滅絕（參考 `PROTOTYPE_NOTES.md` 第 88 項）。
- 修改 `SPEC.md` 中的遊戲規則或數值前，須先說明修改理由並與團隊討論，修改後同步更新相關文件與測試。
- 維持原生 JavaScript 開發架構，不任意新增第三方套件。
- 涉及 UI 或操作流程的修改，除自動化測試外，亦須進行瀏覽器端的手動操作測試。
